Three execution modes, per-case auto/manual timeout, immediate completion, per-case loop results, distinct terminal statuses, safe semantic ER/AR, detailed CSV, high-importance result notification, one bounded return retry. Existing plans infer mode from presence of scenarios. No automatic reset of app data. Cloud status TIMEOUT/BLOCKED maps to INCOMPLETE for current rule compatibility; full session status is preserved. Direct idempotent report creation fixes missing-document read denial. Local report limit 150 cases per target: stop visibly rather than overwrite. Pause is supported for fixed duration only; adaptive execution must stop instead of replaying partially performed actions. Old reports are retained, missing data not invented. No new permissions or Firestore rules. Device and real Firebase acceptance outstanding.
