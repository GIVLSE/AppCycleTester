# Sequmio — черновик для Google Play (RU)

**Название:** Sequmio

**Краткое описание:** Автоматические циклы запуска Android-приложений для QA-тестов.

**Полное описание**

Sequmio помогает тестировщикам и разработчикам проверять работу нескольких Android-приложений последовательно.

Выберите установленные приложения, настройте индивидуальное время нахождения на экране и порядок запуска. Доступны однократный прогон, заданное количество циклов, бесконечный режим с общим лимитом времени, пауза и остановка. Локальный журнал фиксирует результаты и ошибки.

Для автоматического переключения используется служба специальных возможностей Android (Accessibility Service). Она проверяет, какое приложение находится на экране, но V1 не записывает нажатия, текст экранов, скриншоты или видео. Включение службы выполняется вручную после согласия пользователя.

**Подготовить отдельно:** скриншоты с реального телефона, иконку, feature graphic, категорию, возрастную декларацию, Data Safety, видео для декларации Accessibility API, контактный email и ссылку на опубликованную политику конфиденциальности.

**Публикация:** Closed testing only; не включать Open testing или Production до отдельного решения.
