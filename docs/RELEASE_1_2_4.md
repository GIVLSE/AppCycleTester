# Sequmio 1.2.4 (25)

Join: links left, Confirm/Confirmed glass pills right. Existing confirmation states, cancellation and persistence unchanged.

Accessibility: try AOSP service-specific intent with flattened component string; fall back to public Accessibility settings action, then system Settings. Separate public-menu button remains available when an OEM accepts the direct intent but shows an unrelated screen. Manufacturer-specific manual path for Samsung and Xiaomi-family devices. No privileged APIs or automatic enablement; actual OEM navigation requires device acceptance testing. No guarantee of a direct Installed apps page on One UI.

No Firestore rules changes in this release. Deployment of v1.2.3 icon rules remains required before publishing icons; previously published listings remain readable.
