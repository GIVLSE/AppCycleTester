Privacy Policy

Effective date: November 23, 2026 · App: Sequmio (com.sequmio.givlse)

This policy describes the data used by Sequmio, an Android app-testing utility developed by Vladislav Girskii (GIVLSE).

1. What Sequmio does

Sequmio helps you create test plans that open selected installed Android apps one after another, each for a specified duration. It supports repeated runs and locally stored test history.

2. Information accessed on your device

  • Launchable installed apps: application display names, package identifiers and launcher activities to show a list of apps that you can select.
  • Test plans: selected apps, execution order, per-app durations, repeat options and time limits.
  • Foreground app events: the active app's package identifier and window-change timestamps detected by the user-enabled Android Accessibility Service.
  • Execution history and reports: local time-stamped run events, app identifiers, test timings, retry counts, PASS/FAIL status and structured session reports (JSON/CSV format).
  • Consent setting: a local record of your acknowledgement of Sequmio's Accessibility Service disclosure.

These items are used solely to run the test plan you requested, check app switching, and display results.

3. Accessibility Service

Sequmio requests use of Android's Accessibility Service to launch apps you select and detect which app is active. This service is enabled only by you in Android system settings after a prominent disclosure and an explicit consent step.

The current version does not read on-screen text, record taps or gestures, take screenshots, record audio or video, or run an E2E recording feature.

You can revoke this access at any time in Android Settings → Accessibility. Automatic app cycling will not work without this service.

4. Foreground execution and notifications

While you run a test, Sequmio uses a user-initiated Android foreground service and an optional system notification with a Stop action. The service uses a partial CPU wake lock to keep timers responsive, but cannot prevent other apps' screens from locking. Android notification access is optional and can be changed in Settings.

5. Storage, data sharing and security

Test plans, consent setting and execution history are stored locally on your device using Android SharedPreferences. Sequmio does not automatically transmit these records to the developer or third parties, and it has no analytics, advertising, user accounts or remote backend. Users can explicitly select Share JSON or Share CSV in History to send a chosen report to another app; the selected recipient's privacy policy then applies. No personal information is sold.

Because this information is stored locally, anyone with access to your unlocked device may be able to view the test log in the app. Protect your device with Android's normal screen-lock security.

6. Retention and deletion

The app keeps selected test settings until you change or delete the app's local data. Its execution log keeps recent events, and local structured reports are limited to the most recent 40 sessions. You can delete all locally held Sequmio data by clearing its storage in Android Settings or uninstalling the app.

7. Children

Sequmio is designed for developers and app testers and is not directed at children.

8. Changes to this policy

If future versions add E2E recording, screenshots, automatic sharing or new data processing, this policy and the related in-app disclosure will be updated before those features are introduced.
