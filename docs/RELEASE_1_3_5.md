# Sequmio 1.3.5 — release candidate
- QA Progress: account-scoped local activity over 14 calendar days, actual completed PASS and FAIL, no claim of Play eligibility. Data starts with this version; historical unscoped progress not migrated.
- Reminders: off by default, approximate local-time delivery via WorkManager, one per day if installed joined apps have no completed test today; no exact alarm or automatic test launch.
- Screenshot Evidence: off by default, API 34+, verified target application window at confirmed required assertion FAIL, 900ms maximum capture wait. Skip editable/password nodes and protected windows. Up to 20 JPEGs/account, 200 KB each, seven-day local retention enforced at access. No automatic uploads. Explicit review and confirmation, then attach to existing failed-case metadata report. Cloud access only to submitting tester and original report owner; image removal/account deletion supported. No screenshot export in bulk metadata files.
- Deployment gate: run Android CI and Firestore emulator tests, deploy updated firestore.rules and firestore.indexes.json to the real Firebase project before app rollout. Update Play Accessibility declaration, prominent disclosure and Data Safety as applicable; validate on physical devices (API 33 fallback, API 34+ capture, secure/editable windows, off by default, review/deny/send/remove, account switch, timeout, cancellation, reminder permission/Doze). No background screen capture; no new exact alarm permission.
